**Игра "Крестики нолики"**


Игра предназначена для двоих игроков.


Для того, чтобы поиграть запустите игру. Поочереди делайте ходы. У какого игрока первой будет заполнена диагональ его фигурой, тот побеждает в игре.



При желании повторить игру, или если раунд проиграл в ничью, нажмите на кнопку "заново".
